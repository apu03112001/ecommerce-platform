# Admin and Sales Person Features

## Admin
- Manage products
- Create and manage users
- Change user roles
- View all orders
- View sales statistics

## Sales Person
- Add products
- Edit own products
- Delete own products
- View orders containing own products

## User
- Browse products
- Search and filter products
- Manage cart
- Manage wishlist
- Complete Razorpay test checkout
- View order history
